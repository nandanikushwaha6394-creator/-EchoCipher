# 🔊 Echo Cipher

### AI-Powered Voice Security System

Echo Cipher is an AI-powered project designed to detect
voice cloning and AI-generated voice impersonation attacks.

## 🚀 Features

- 🎙️ Voice Detection Interface
- 🤖 AI-Generated Voice Analysis
- 📊 Analytics Dashboard
- 📜 Detection History
- ⚙️ Settings Page
- 🌐 User-Friendly Web Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Artificial Intelligence
- Machine Learning

## 🎯 Objective

To improve voice security by helping users identify
potentially cloned or AI-generated voices.
